This repository documents my journey of learning frontend development from basics to advanced through consistent practice and real-world projects. The main goal of this repository is to build a strong foundation in core web technologies and gradually move toward modern frontend frameworks and tools. Instead of only focusing on theory, I believe in learning by building, so every concept here is supported with practical examples and mini projects.
Inside this repository, you will find work related to HTML, CSS, JavaScript, and React, along with various UI experiments, components, and small applications. Each folder represents a different stage of learning, starting from basic concepts like page structure and styling, and moving toward more advanced topics such as component-based architecture, state management, and interactive user interfaces.
This repository also reflects my daily practice and continuous improvement as a frontend developer. I try to write clean, readable, and reusable code while following good development practices and version control using Git and GitHub. Over time, this repo will keep growing with more advanced projects and better implementations of earlier concepts.
