What are Events and Events Listeners?

Events: These are actions or occurrences that happen in the browser, such as:

        i. User actions: Clicks, key presses, mouse movements.
        ii. System events: Page loading, errors, timers firing.
        iii. Custom events: Ones you define yourself (e.g., "userLoggedIn").
Event Listeners: Functions (often called "handlers" or "callbacks") attached to 
                 elements that wait for an event to trigger. When the event fires,
                 the listener runs automatically.

NOTE : Without event listeners, JavaScript would be mostly static. They power everything from form submissions to drag-and-drop interfaces.

2. Adding an Event Listener: The Basics

Use element.addEventListener(eventType, callback, [options]):

    i. eventType: A string (e.g., 'click', 'keydown') or an object for custom events.

    ii. callback: The function to run when the event occurs. It receives an event object as its first parameter.
 
    iii. options (optional): An object for advanced config (e.g., { once: true } to run only once).
