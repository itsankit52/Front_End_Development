What is API's.

APIs (Application Programming Interfaces) in JavaScript are sets of rules and functions that enable code to interact with browsers, servers, or external services—e.g., fetching data via Fetch API or manipulating the DOM.

Why use API's in Js.

    Fetch Data: Pull real-time info (e.g., stock prices, news).

    Add Features: Integrate maps, payments (e.g., Stripe API), or social logins.

    Efficiency: Reuse code from others instead of building everything from scratch.
