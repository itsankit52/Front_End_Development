What is BOM in JavaScript?

BOM stands for Browser Object Model.

It allows JavaScript to interact with the browser, outside of the web page content (which is handled by the DOM – Document Object Model).

Example of BOM tasks.

    Get the browser window size

    Redirect to another page

    Show alerts and popups

    Access browser history

    Work with location (URL)

The Browser Object Model (BOM) provides everything JavaScript needs to interact with the browser environment itself – from managing URLs, alerts, and history, to getting browser and screen details. It complements the DOM by allowing control over the browser rather than just the web page.

  • location

    • The location object contains info about the current URL and lets you change it.

  • hisrory

    • The history object allows navigation through the session history.

  • innerHeight & innerWidth

    • These give the viewport’s height and width in pixels.

  • open()

    • Opens a new browser window or tab.

  • close()

    • Closes the current window (only works for windows opened by window.open())

  • resizeBy()

    • Resize the window.

  • resizeTo()

    • Resize the window.

  • moveTO()

    • Move the window on the screen.

  • moveBy()

    • Move the window on the screen.

  • scrollBy(),scrollTo(), scroll()

    • Scroll the page.

  • print()

    • Opens the print dialog.

  • Document

    • The document object represents the DOM (HTML page).
