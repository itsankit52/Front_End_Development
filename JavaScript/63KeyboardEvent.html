What is keyboard event?

In JavaScript, keyboard events are a crucial type of event that trigger when a user interacts with the keyboard. These events help capture user input on a web page and respond to it accordingly. For example, submitting a form on pressing Enter, handling shortcuts (like Ctrl+S), or controlling movement in a game.

Keyboard events work at the DOM (Document Object Model) level and are attached using the addEventListener() method. They can be applied to specific elements like input or textarea, or to the entire document.

There are Three Main Types of Keyboard Events

1. keydown : Fires when a key is pressed down, regardless of whether it's held or released. It works for all keys, including letters, numbers, function keys (F1-F12), and modifier keys (Shift, Ctrl, Alt).

Use case : Ideal for game controls or shortcuts.
Example : Moving a character with arrow keys.

2. keyup :Fires when a key is released

Use case : Tracking the end of a key press, like in typing counters.
Example : Stopping an animation when a key is released.

3. keypress : Previously fired only for printable keys (e.g., letters, numbers) on press. Avoid it as it's no longer standard. Use keydown instead.

NOTE : Both keydown and keyup support bubbling, meaning they can propagate to parent elements. keypress did too.
