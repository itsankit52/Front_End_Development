Node vs Element in Js.

1. What is a Node?

    A Node is any type of object in the DOM tree.

    In HTML, the DOM (Document Object Model) represents everything as a node:

    Elements (div, p, h1, etc.)

    Text inside elements

    Comments ()

    Document itself (document)

    Attributes of elements

NOTE : Every element is a Node, But not every Node is an element.

2. What is an Element?

    An Element is a specific type of Node — it represents an HTML tag (like div, p, h1, etc.).

    So:

    Element = Node that represents a tag

    Not all nodes are elements (text or comments aren’t)
