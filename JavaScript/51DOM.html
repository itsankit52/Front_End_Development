Document Object Model (DOM).

The DOM (Document Object Model) in JavaScript is a programming interface that allows to access, change, add, or delete elements in a web page dynamically.

The DOM represents the structure of an HTML document as a tree of objects.

Each element (like p, div, h1) becomes a node in this tree.

DOM Tree Structure.

        Document
            └── html
                ├── head
                │   └── title
                └── body
                    ├── h1
                    └── p
