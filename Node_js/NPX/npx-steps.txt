What NPX does:
- Executes Node.js package binaries without global installation
- Uses Node.js internally to run JavaScript-based tools

Execution Steps:

Step 1:
- Check ./node_modules/.bin in current project
- If binary exists → execute it

Step 2:
- Check globally installed packages
- If found → execute it

Step 3:
- If not found:
    - Download package temporarily from npm registry
    - Execute it
    - Clean up afterward (may cache)

Notes:
- NPX does NOT execute arbitrary files (use node for that)
- NPX relies on binaries defined in package.json "bin"
- script-shell config is unrelated to NPX execution

************************************************************
    node → run code
    npm → install packages
    npx → run packages without installing
