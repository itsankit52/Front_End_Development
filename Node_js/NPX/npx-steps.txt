What NPX does? 
    . Search for a file and execute it.(File can be anything like app.js, app.abc, xyz etc...)
    . NPX does not use node to execute a file, NPX direct excute file 


Search Step 1. 
    1.1. Search for package.json in current working directory -> if not found then move to step 2

    1.2. Searches for name key in json file -> if found then goto search for bin (binanry) key


Search Step 2.
{npm config get script-shell} -> "null" by default 
{npm config set script-shell} -> give bash path  
    1.1. Searches for (node_modules\.bin\hello) folder in current working directory
