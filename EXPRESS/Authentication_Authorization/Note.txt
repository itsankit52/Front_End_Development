1. Authentication (AuthN)
    Authentication means verifying the identity of a user.

    Example : 
        Suppose we have a college management system.

        A user enters:
        Email: ankit@gmail.com
        Password: 123456

        The server checks:
            Does this email exist?
            Is the password correct?

            If yes → User is authenticated (logged in).

            If no → Login fails.

-----------------------------------------------------------------------------------

2. Authorization (AuthZ)
    Authorization means checking what an authenticated user is allowed to do.

    Example
        Imagine there are 3 users:
            Student
            Teacher
            Admin

    Permissions:

    Role	    ->      Permissions
    Student	    ->      View profile
    Teacher	    ->      Upload marks
    Admin	    ->      Add/Delete users

    If a student tries:

    DELETE /users/123

    The server says:
        403 Forbidden

    Because the student is authenticated but not authorized.
